| 1.0.0 | Release candidate: a review of the whole program before the first stable release, six reviewers and six fixers over disjoint parts, about 90 fixes with tests. Pipeline: a fully checked take beats an unchecked one, `--force` no longer wipes the synth cache in regen rounds, `score --force` recomputes, a missing reference voice is an unchecked gate, a cancel between chunks keeps finished takes, CSV translation import takes the translation column, a model that fails to load is not announced as a substitution, a load failure with parallel translation fails once, null arousal no longer crashes route A, speaker embeddings are recomputed after a design change, casting edits survive an RVC training, short clips are no longer over-amplified, tempo is derived for non-Japanese scripts, unknown scripts are not labelled Russian, ruaccent works offline after an environment rebuild (its koziev data is kept next to the weights). Backends: VoxCPM2 works again (an invented `seed` argument failed every take), F5-TTS Russian loads offline (Vocos vocoder pulled), Zonos2 gets the real command line and the shipped exe names, MOSS-TTS lists its real VRAM (14.5 GB), Chatterbox no longer downloads an unused 2 GB file, honest weight sizes, ffmpeg from a stable mirror, `vndub --version` is right. App: app.log rotates (it stopped after 2 MB), a job that cannot be saved no longer kills the worker, settings writes retry when the file is being read, Cancel reaches a model that is still loading and the pack step of Apply, Continue keeps forced work and is withdrawn once the job ran again, the process sweep never kills the user's own processes and a drive root is refused as a folder, installs are refused while a job runs, the exit watchdog cannot hang on the sweep, the uninstaller does not wait on the reaper, Help screenshots load, Diagnostics no longer crashes on a GPU with unknown memory (and an error boundary replaces a blank window), install counters show the right units and counts, a partial rollback is reported, a voice change is not reverted by a slider, per-line tuning starts from the character's, regenerated takes play fresh audio, job panels survive navigation, the live log keeps following, the data-folder change reloads the app |

| 1.1.0 | Ren'Py: the translated text reaches the screen. `pack` writes `game/tl/<language>/vndub_dialogue.rpy` (one `translate <language> <dialogue id>:` block per translated say line, the shape `renpy translate` writes, with the line's `voice` statement kept; a `translate <language> strings:` block for menu choices and captions) and `game/vndub_language.rpy` (`define config.language`), so the game starts in the dub's language instead of speaking Russian over English text. Config `pack.renpy.text` (`enabled: auto | true | false`, `language`, `font`; auto = the project has a translation); `manifest_patch.json` gets `text`, INSTALL.md the section "The translated text" with the undo, a full pack removes the scripts when the feature is off; lines whose translation lost an interpolation or flow tag, menus without `choices_tgt` and ids/strings the game already translates stay in the original language and are listed under `text.skipped`. The desktop app's install step has a note about it. Not yet run in a real Ren'Py (no SDK on the build machine). Russian laughs like "Эхехехе", "Ихихи", "Уфуфу", "Кукуку", "Ня-хаха" are detected (they were read letter by letter), `unstress_laughs` also clears U+0301, and the `ru` nervous spelling is now "Эхехе...". Russian stress: words ruaccent left bare ("Даже", "Хотя", "тебя", a verb after "...") are marked from its dictionary and accent network, a line with straight quotes keeps its marks instead of losing them all, and `translate.stress.yo` is now `safe` by default (ё only for words that exist only with ё: no more "по нёбу", "узнаём" for "узнаем", "самоё"). Translation quality: the glossary has a `player` entry (name, gender m / f / unknown) and the prompt makes words said to the player agree with it (the app's step 2 has "Main character (the player): gender", default not specified: wordings without gender, the masculine when impossible); a names pass asks the model once for the canonical spelling of the script's proper nouns (Gensokyo, Patchouli ...) and adds them to the glossary terms (`translate.names_pass`, cached, never overwrites a term you wrote); after translation a glossary spelling missing from a line is logged and counted (`glossary_misses`) and a mixed-script or untranslated answer is asked again once (`check_failed` when it stays wrong); new prompt rules: write the letter yo, standard laughter and sound spellings, idioms by meaning without omissions, names exactly as listed; a model that does not fit at its context (gemma4_12b on 8 GB) is tried at 8192 and 4096 with proportionally smaller batches before the next model (still never a partial offload; with the default 0.5 GB margin the 12B model still does not fit an 8 GB card); `translate.include_narration` (auto = Ren'Py) translates narration as text-only lines that never reach synth, and menu choices are stored as `choices_tgt` on the menu's translation record. A project translated before is translated again once (cache protocol 3). Non-speech sounds: the prompt asks the model to name snoring, kisses, yawns, gasps, sneezes, coughs, hums, huffs, shivers and eating noises (`sound: {kind, only}`), regexes are the fallback, and a line that is nothing but such a sound ("ZZZ...", "Muah!") gets the table's spelling for the target language (`configs/sounds.yaml`: "Хр-р-р... хр-р-р...", "Чмок!") instead of the model's letter-by-letter "З-З-З..."; the translation record has `sound`, the flags `sound` / `interjection` / `sound_spelled`, and the text-emotion delivery has a `sound` event and note (`text_emotion` stage version 3). Synth, score and pack handle those sounds (`synth.sounds`: the table spelling or the backend's tag, a recorded clip per kind (`only: sample`, one candidate, no model) or silence (`only: silent`, listed in the patch coverage as `sound_silent`) for a line that is nothing but a sound; sounds are taken out of the CER reference and a sound-only line has no CER gate; a sample candidate passes unchecked). |
