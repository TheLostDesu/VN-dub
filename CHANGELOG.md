# Changelog

| Version | What was added |
|---------|----------------|
| 0.2.0 | The installer carries everything it needs: VC++ runtime, MinGit, bgi-extractor; adapters start from the right environment; smoke test of the exe |
| 0.3.0 | Round 3: processes end when the window closes, the interface keeps jobs across tabs, install folders, one shared torch environment `main` (an incompatible change: old environments have to be recreated) |
| 0.4.0 | Round 4: the script's language is detected, diagnostics for empty model answers, batched adapters |
| 0.5.0 | Round 5: models don't silently end up running from system RAM |
| 0.6.0 | Round 6: the Cancel button works everywhere: model processes are killed at once, the translate stage has progress, pause and cancel, the button shows "Cancelling..." |
| 0.6.1 | Round 6.1: translation runs once (step 2); the preview and the full run no longer translate again |
| 0.6.2 | Round 6.2: the time estimate is honest: the speed is the average since the stage began (model loading and the wait for a batch count), shown in lines a minute; cached results and pauses no longer skew it, stages are added up per line, the first estimate comes from the previous run |
| 0.6.3 | Round 7: model processes never outlive the app (process ledger, startup sweep, a reaper that survives a crash, no adapter restart after Cancel), every job log line has a time and the whole log is kept in a file, app.log tells what the app did (jobs, stages, processes, errors, settings; a detailed mode in Settings), the interface is aligned, a job chip in the top bar, the window title and taskbar say when a job is done |
| 0.6.4 | Round 8: a model that does not fit is a visible warning, not a silent downgrade (synth stops instead of deleting candidates, score sends unchecked lines to review, the translate cache knows which model answered); an interrupted run keeps its score metrics and route-B voices; Continue picks the heavy job, keeps the other interrupted ones, drops the shutdown flag unless re-ticked and names changed settings; the speed estimate no longer collapses after Continue |
| 0.6.5 | The speed is honest again: a batch of lines reported one by one counts as work, not as cached results (it showed about ten times too slow) |
| 0.6.7 | Round 9: a re-take round after the quality check is shown as a retry inside that step (the run no longer seems to go back to voicing), the counter says takes, not lines; a line whose every take misreads the text goes to review at once instead of through two re-take rounds, and an empty ASR transcript is an unchecked gate, not a failed one |
| 0.7.0 | Round 10: every line with a take is in the patch (a take that failed the checks is installed as provisional and the patch, the report and the app say how many; before, those lines were silently left out), Ren'Py dialogue ids computed as Ren'Py does (per file, menus, monologues), the app warns when a game was imported by an older version; written laughter (haha, hehe, ха-ха, *laughs*) is detected in every language, respelled or tagged for each voice model instead of read letter by letter, and no longer fails the intelligibility check; the download file list is a scroll box with a summary line; Fish S2 Pro and MOSS-TTS 1.5 point at GGUF weights that exist (audio.cpp), Zonos 2 weights download again, a network test guards every model repo |
| 0.7.1 | CosyVoice 3 loads again: a funasr environment built since January pulled ruamel.yaml 0.19, which broke the old loader HyperPyYAML parses the model config with (`'Loader' object has no attribute 'max_depth'`, the preview failed at once); the pins now ask for ruamel.yaml 0.18 and the adapters give an already built environment the missing attribute, so nothing has to be recreated |
| 1.0.0 | Release candidate: a review of the whole program before the first stable release, six reviewers and six fixers over disjoint parts, about 90 fixes with tests. Ren'Py: scripts from `.rpa` archives and decompiled `.rpyc` are parsed again (the filter dropped everything extracted into `work/raw/renpy`), Cyrillic and CJK character names, `Character(kind=e)` inherits its name, a unicode escape without hex digits no longer aborts parse, dialogue ids follow the translate blocks exactly (voice statements and `nvl clear`, `tlid_only_considers_say` chosen by the game's Ren'Py version), same-named `.rpyc` in two folders no longer overwrite each other, the auto-voice fallback binds only an unambiguous file, lines with a `voice` statement of their own are reported as not installable instead of counted as dubbed, a full pack removes the previous patch's stale files (imports by an older version show the re-import warning: parse version 4). Pipeline: a fully checked take beats an unchecked one, `--force` no longer wipes the synth cache in regen rounds, `score --force` recomputes, a missing reference voice is an unchecked gate, a cancel between chunks keeps finished takes, CSV translation import takes the translation column, a model that fails to load is not announced as a substitution, a load failure with parallel translation fails once, null arousal no longer crashes route A, speaker embeddings are recomputed after a design change, casting edits survive an RVC training, short clips are no longer over-amplified, tempo is derived for non-Japanese scripts, unknown scripts are not labelled Russian, ruaccent works offline after an environment rebuild (its koziev data is kept next to the weights). Backends: VoxCPM2 works again (an invented `seed` argument failed every take), F5-TTS Russian loads offline (Vocos vocoder pulled), Zonos2 gets the real command line and the shipped exe names, MOSS-TTS lists its real VRAM (14.5 GB), Chatterbox no longer downloads an unused 2 GB file, honest weight sizes, ffmpeg from a stable mirror, `vndub --version` is right. App: app.log rotates (it stopped after 2 MB), a job that cannot be saved no longer kills the worker, settings writes retry when the file is being read, Cancel reaches a model that is still loading and the pack step of Apply, Continue keeps forced work and is withdrawn once the job ran again, the process sweep never kills the user's own processes and a drive root is refused as a folder, installs are refused while a job runs, the exit watchdog cannot hang on the sweep, the uninstaller does not wait on the reaper, Help screenshots load, Diagnostics no longer crashes on a GPU with unknown memory (and an error boundary replaces a blank window), install counters show the right units and counts, a partial rollback is reported, a voice change is not reverted by a slider, per-line tuning starts from the character's, regenerated takes play fresh audio, job panels survive navigation, the live log keeps following, the data-folder change reloads the app |
